# Portafolio — Gabriel Pérez Bárcenas

Portafolio personal de **Gabriel Pérez Bárcenas**, Ingeniero en Tecnologías de la Información y Desarrollador Web Jr., egresado de la Universidad Politécnica del Estado de Morelos.

🔗 **Sitio en vivo:** [gabrielpbsow.github.io/portafolio](https://gabrielpbsow.github.io/portafolio/)

## Sobre el proyecto

Un solo archivo `index.html`, construido con HTML, CSS y JavaScript vanilla (sin frameworks), con temática de terminal/consola para reflejar mi interés en redes, automatización y sistemas.

## Features

- 🖥️ Diseño con estética de terminal (comandos de shell simulados como encabezados de sección)
- 🌗 Toggle de tema claro/oscuro con persistencia en `localStorage`
- 🌐 Toggle bilingüe ES/EN, con traducción de textos, meta tags, alt text y atributos de accesibilidad
- 📂 Seis proyectos en una cuadrícula filtrable (Web / IA & Datos / Sistemas / Móvil)
- 📊 Widget de contribuciones de GitHub
- 📄 Descarga directa de CV en PDF
- 💬 Botón de contacto por WhatsApp y correo con mensaje prellenado
- 🏆 Certificados embebidos con vista previa

## Stack

`HTML5` · `CSS3` · `JavaScript (vanilla)` · `Font Awesome`
